# Stategraph Roadmap

What we're planning to build next at [Stategraph](https://stategraph.com).

The roadmap is on the [project board](https://github.com/orgs/stategraph/projects) (Stategraph Roadmap).
Each item is an issue in this repository: comment or react to tell us what matters to you.

Months are our current plan, not promises. The roadmap is updated monthly.
